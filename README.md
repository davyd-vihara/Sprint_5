# Проект «Доска» - UI Autotests

Проект для автоматизации тестирования учебного сервиса объявлений «Доска».

## Описание
Тестируется полная функциональность сайта:
- Регистрация новых пользователей
- Авторизация существующих пользователей  
- Выход из системы (Logout)
- Создание объявлений (авторизованными и неавторизованными пользователями)

## Используемые технологии
- **Python 3.10+** - язык программирования
- **Selenium WebDriver 4.0+** - автоматизация браузера
- **pytest 8.0+** - фреймворк для тестирования
- **Page Object Pattern** - архитектура проекта

## Поддерживаемые браузеры
- Тесты запускаются и проверяются в браузере:
- `Google Chrome` (основной для ревью)

## Структура проекта

- **data/** - Тестовые данные
  - `test_data.py` - Константы и генераторы данных
- **helpers/** - Вспомогательные функции
  - `generators.py` - Генераторы тестовых данных
- **locators/** - Локаторы элементов
  - `auth_page_locators.py`
  - `create_ad_locators.py`
  - `main_page_locators.py`
  - `profile_locators.py`
- **pages/** - Page Object Model
  - `auth_page.py` - Авторизация/регистрация
  - `base_page.py` - Базовый класс страницы
  - `create_ad_page.py` - Создание объявления
  - `main_page.py` - Главная страница
  - `profile_page.py` - Профиль пользователя
- **tests/** - Тестовые сценарии
  - `test_create_ad.py` - Тесты создания объявлений (2 теста)
  - `test_login.py` - Тесты авторизации (1 тест)
  - `test_logout.py` - Тесты выхода из системы (1 тест)
  - `test_registration.py` - Тесты регистрации (3 теста)
- `.gitignore` - Исключаемые файлы
- `config.py` - Конфигурация проекта. Настройки проекта (BASE_URL, TIMEOUT, браузер)
- `conftest.py` - Фикстуры pytest
- `README.md` - Документация
- `requirements.txt` - Зависимости

## Установка
### 1. Клонировать репозиторий:
    git clone git@github.com:davyd-vihara/Sprint_5.git
### 2. Перейти в папку проекта:
    cd Sprint_5
### 3. Установить зависимости:
    pip install -r requirements.txt
### 4. Убедиться что ChromeDriver доступен в PATH

## Запуск тестов:
### Запуск всех тестов:
    pytest -v tests/
### Запуск конкретного тестового файла:
    pytest -v tests/test_registration.py
### Запуск с подробным выводом:
    pytest -v -s tests/
### Запуск тестов с генерацией отчета:
    pytest -v tests/ --html=report.html

## Тестовые сценарии
### Регистрация пользователя (3 теста)
  - Успешная регистрация нового пользователя
  - Регистрация с email не по маске
  - Регистрация уже существующего пользователя
### Авторизация (1 тест)
  - Успешный вход в систему
### Выход из системы (1 тест)  
  - Успешный выход из системы
### Создание объявлений (2 теста)
  - Попытка создания объявления неавторизованным пользователем
  - Успешное создание объявления авторизованным пользователем

## Особенности реализации
  - **Генерация тестовых данных**: Уникальные email и пароли для каждого теста
  - **Фикстуры pytest**: Централизованное управление драйвером и тестовыми данными
  - **Конфигурация**: Все настройки вынесены в config.py
  - **Обработка ошибок**: Graceful degradation при отсутствии элементов
